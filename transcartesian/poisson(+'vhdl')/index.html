The grid below is used both to input source data (outer nodes contain boundary values, inner nodes contain charge distribution)
and to output a Poisson equation solution.
Type in boundary values and charge distribution respectively and save the data with 'Save boundary values and charge distribution'.
Alternatively, you can enter hardware-coded source data with the 'Seed Sample Data' button, edit if needed, and also save this data.
You can view the content of source data buffer by pressing the button 'Show boundary values and charge distribution'.
To solve the Poisson equation, click the 'Solve' button, the mesh is filled with the solution data.
This workflow does not result in an idempotent process, and saving the solution results as a new source data followed by subsequent
solving of the equation gives the results that have no easily seen useful interpretation.
