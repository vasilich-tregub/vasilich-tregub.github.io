A mesh enumerating the discretized plane points with one variable is built.
The mesh is a map with the key enumerating the mesh nodes and the value
which is an array of the node's closest neighbors.
A 256-node mesh is generated with a sort of 'lifting' scheme: the process
starts with a four-node mesh, which is quadruplated into a 16-node mesh,
then to a 64-node mesh, and finally to a 256-node mesh.
Press the button, and see printout in devtools' console.
The generator of an arbitrary size mesh can be implemented as either
iteration or a recurrent function.
