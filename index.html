  • LeGall 5/3 wavelet transform of images. DWT is implemented in
    a WebAssembly module. Clicking an image thumbnail computes in-place
    an interleaved wavelet transform of the clicked image and draws the result
    underneath; the button `Inverse Transform` computes an inverse transform,
    recovering the source image (also in place; can take long as the vertical
    inverse transform is not optimized in code). Set levels of decomposition
    in both directions, horizontal and vertical. For comparison, this is
    a page with DWT implemented in pure JS. Compare the WebAssembly
    performance with the DWT implemented in C.
    The JS-implemented page also features histogram representation (button
    `Histogram`). The histo plot is normalized and can be zoomed. Type in
    fractional or large values, then press the histo button again. To operate
    on the source image, restore the image by `Inverse Transform` button
    before you press `Histogram`. Use the 'De-interleave' button to see
    a deinterleaved decomposition.
    Credit: the images are downloaded from the NASA website and used
    with the owner permission.
