  • Busy Beavers simulation
    This is a demo of the two-symbol TM Busy Beaver challenge champions.
    Select the number of states with radio buttons at state markers A/B/C/D/E.
    For now, BB(2,5) runs over a minute or even longer. The page may warn you
    "The page isn't reponding". Click the Wait button to continue.
    The results are printed into the textarea control. The hat ('^') character
    inserted before the symbol on a tape cell marks the starting position. The
    halt position is marked with the dot inserted after the tape cell accessed
    last.
    Max shifts number is preset to the 47,176,870 which is the maximum shift
    number of the BB(2,5) champion. You can decrease this number to, say,
    47,176,000 and examine the behaviour of the tape before the halt state.
    It is unrealistic to examine with this script the behaviour of the current
    champion 1RB3RB5RA1LB5LA2LB_2LA2RA4RB1RZ3LB2LA, but you
    can watch 'A Start in Life' drama while selecting the radio button near state F
    and setting the max shifts number to any number you like.
    Please note that you can resize the textarea control, dragging it with the
    lower buttom corner. You can also improve the program so that it will be
    able to continue from the state which it enters when reaching the current
    max shifts parameter.
