  • Busy Beavers simulation
    This is a demo of the two-symbol TM Busy Beaver challenge champions.
    Select the number of states with radio buttons at state markers A/B/C/D/E.
    For now, BB(2,5) runs about four seconds. If the TM run is longer, the
    page may warn you "The page isn't reponding". If you want to continue,
    you can ignore the warning or click the Wait button.
    You can enter TM instructions manually. The validity check is only
    rudimentary: if you enter an invalid 3-char rule, it is silently replaced
    with an empty string, and it is the only message you've got from the page.
    Run diagnostic is also nearly absent: this is a demo, not a debugger.
    After TM halts or exits, the js script writes the final tape to the textarea
    control. The hat ('^') character is not a symbol the program places on the
    tape; it marks the starting position. The halt position is marked with the
    dot inserted after the tape cell accessed last. A default limit on the
    number of shifts is preset to an arbitrary value of 65,536. When an BB(2,N)
    champion is selected, the limit on S value is set to the champion's S value
    plus one. It is unrealistic to examine the behaviour of BB(2,6) contenders
    like 1RB1RA_1RC1RZ_1LD0RF_1RA0LE_0LD1RC_1RA0RE
    with this script, but you can watch 'A Start in Life' drama while selecting
    the radio button near state F and setting the max shifts number to any
    number you like. You can use preset rules for either of two BB(2,6)
    machines on the page or enter your own data for rules. You can also
    improve the program so that it will be able to continue starting from the
    state which it enters when reaching the current max shifts parameter.
