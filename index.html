  • Web assembler implementation of TM for Busy Beavers challenge champions.
    The performance is as good as that available with the C implementation.
    The program stops computations for BB(2,6) contenders when it runs out of
    available cells on its TM tape implemented with a single 64K memory page.
    Turing machines of BB(2, N) champions implemented in C.
  • LeGall 5/3 wavelet transform of images. DWT is implemented in the
    WebAssembler module. Clicking an image thumbnail computes in-place
    an interleaved wavelet transform of the clicked image and draws the
    result underneath; the button `Inverse Transform` computes an inverse
    transform (also in place), recovering the source image. You can set levels
    of decomposition in both directions, horizontal and vertical.
    Be patient when computing for the larger image, the page can become
    irresponsive as the processing time noticeably increases.
    For comparison, this is a page with DWT implemented in pure JS.
    Both pages are defaulted to a single-level decomposition in the horizontal
    direction where the performance gain given by WASM is pronounced the
    most; with higher levels and especially for the vertical direction, this gain
    is tending to disappear as the skips of strided memory access in transform
    loops are greater for higher levels; in the vertical direction, the skips
    add to their values the bitmap stride.
