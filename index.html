  • Busy Beavers simulation
    This is a demo of the two-symbol TM Busy Beaver challenge champions.
    Select the number of states with radio buttons at state markers A/B/C/D/E.
    For now, BB(2,5) runs over a minute or even longer. The page may warn
    you "The page isn't reponding". If you want to continue, you can ignore
    the warning or click the Wait button.
    You can enter TM instructions manually. The validity check is only
    rudimentary: if you enter an invalid 3-char rule, it is silently replaced
    with a string '0LH', and it is the only message you've got from the page.
    The results are printed into the textarea control. The hat ('^') character
    is not the symbol on the tape; it marks the starting position. The halt
    position is marked with the dot inserted after the tape cell accessed last.
    A limit on the number of shifts is preset to the 47,176,870 which is the
    maximum S value of the BB(2,5) champion. You can decrease this number
    to, say, 47,176,000 and examine the behaviour of the tape before the halt
    state. It is unrealistic to examine with this script the behaviour of the
    current champion 1RB3RB5RA1LB5LA2LB_2LA2RA4RB1RZ3LB2LA,
    but you can watch 'A Start in Life' drama while selecting the radio button
    near state F and setting the max shifts number to any number you like. You
    can use preset rules for either of two BB(2,6) machines on the page or enter
    your own data for rules. You can also improve the program so that it will be
    able to continue starting from the state which it enters when reaching the
    current max shifts parameter.
