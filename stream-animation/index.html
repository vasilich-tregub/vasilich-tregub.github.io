• Streaming from a canvas to a video element. Just assign video.srcObject
    to the stream returned by canvas.streamCapture(). Frame rate is set with
    the `setInterval` call in the `animateColumnWith()` function (`Animation`
    button click event handler)
  • Canvas animation using the `requestAnimationFrame` call Note a steady
    frame duration figure calculated as the difference between the timestamps
    passed to the callback (`drawText()`) in two consecutive frames.
  • Push frames to an array for later retrieval. Animation frames are pushed
    into the array without waiting for the source canvas updates, and we see
    only the final frame when recording is complete. When we select the
    frame number (`Display frame #`) in the UI, the saved frame is drawn
    to the canvas `storedFrame` (if there are any). The exersize is authored
    to appease the other people's curiosity, with canvas image data being
    saved without compression, so the `Frames to record` value set too high
    may crash this script (e.g., 'Out of memory at ImageData creation').
