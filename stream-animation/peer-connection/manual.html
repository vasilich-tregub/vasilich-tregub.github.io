This exercise demonstrates how a browser can use WebRTC for sending video stream
to a peer browser, both browsers can be open in two computers connected with a link
and not necessarily internet enabled.

The page 'Transmitter' (XMIT) initiates connection generating 'offer' (WebRTC
concept) that has to be communicated to the peer computer. For the instructional
purpose, I do not engage in an http server that should be made available to both
computers (typically WebSockets are used to the purpose); instead, I output this
'offer' programmatically in a stringified form to the text control. A learner can
copy the content of this control to the clipboard, paste it to the text document
and send the doc to the other computer via mail, messenger or shared network folder.

In the peer computer, the user opens the page 'Receiver' (RCVR) in the browser and
paste the offer to a dedicated control. To make the process easier, I provided the
buttons "Copy 'offer'/'answer' to clipboard". The browser readily copies to clipboard,
but issues a warning when you try to paste a clipboard content to the page
programmatically, so I relegated it to the user a job of pasting offers/answers to
target controls. The workflow logic is hopefully clear from the webpages' layout and
labels, the logic in javascripts can also help: the purpose is to demonstrate WebRTC
APIs and tricks, and the user should examine the sources anyway.

The clipboard exchange is handy when two browsers are on the same computer. So
the user can first examine the-same-host scenario, and then verify that the
different-host scenario also works. I tested this scenario with a WSL2-to-Windows
host experiment, the clipboard is shared by both browsers in this case.

To verify that the connection is established, the user can verify the operation with
the 'chat' controls. You can see in the code that the video transmission starts
immediately after you copy RCVR's answer to the XMTR ICE input control and
press 'Done!'. You may only need click the Play button (►) of the RCVR video
control.

If physically different, both computers used in this exercise must be in a common
local network!
